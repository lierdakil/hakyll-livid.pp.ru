Gnome в своей бесконечной мудрости недавно отключили по умолчанию вставку по
среднему клику, таким образом отправив в мусор 30 лет мышечной памяти
пользователей. Абсолютно гениальный ход, но чего ещё ждать от Gnome с другой
стороны.

Как можно угадать по тону, я ни разу не пользователь гнома, проблема в том, что
куча приложений на базе gtk -- в частности вездесущий chromium и следовательно
electron -- вслед за ним сделали то же самое. И как включить его обратно
оказалось не вполне очевидно.

<!--more-->

В общем вкратце. Управляется это поведение через dconf. Что делать если dconf
нет? Смириться или поставить. Или патчить сырцы и пересобирать всё. Других
опций, похоже, нет, что, конечно, бред.

Под ключом `org/gnome/desktop/interface` есть булевская опция
`gtk-enable-primary-paste`, её надо поставить в `true`. Способов это сделать
много разных, можно в лоб

```bash
dconf write /org/gnome/desktop/interface/gtk-enable-primary-paste true
```

Под гномом говорят можно через gsettings (сам не пробовал):

```bash
gsettings set org.gnome.desktop.interface gtk-enable-primary-paste true
```

Или через gnome-tweaks, есть там такая галочка. Но это тоже только под гномом.

Я на NixOS, поэтому у меня что-то такое душераздирающее в `configuraiton.nix`:

```nix
{
  # ...
  programs.dconf = {
    enable = true;
    profiles.user.databases = [
      {
        settings = {
          "org/gnome/desktop/interface" = {
            gtk-enable-primary-paste = true;
          };
        };
      }
    ];
  };
  # ...
}
```

В общем с нетерпением жду когда через пару лет они решат что эту опцию надо
вообще удалить /s
